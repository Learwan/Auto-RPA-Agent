Compatibility Notes

支持任何 OpenAI-compatible Chat Completions 服务，只要提供兼容的 Base URL、API Key 和模型名称。

若你同时开启了远端 LLM 与本地模型，远端文本 LLM 会优先使用这里的配置；本地视觉仍按本地视觉开关独立判断。

保存后无需改 `.env` 文件，但正在持有旧 client 的长生命周期对象可能要在下次请求时才会切换到新配置。
